## Findings

Two mismatches found by the companion ui-audit and **fixed in this branch**
(image-gen-on-default silently un-defaulting the org; Add-Model context
override dropped by `create_model`) plus one recorded P4 (double routing-hint
seed when one model holds both defaults). Details, repro, and root causes:
`docs/feedback-loops/ui-audit-2026-08-04-models.md`.

Environment note: backend uvicorn `--reload` can wedge on shutdown while
apscheduler jobs run ("Waiting for background tasks to complete") — after
editing backend files mid-session, expect to kill and restart `main.py`; this
is a dev-sandbox quirk, not a product finding.
