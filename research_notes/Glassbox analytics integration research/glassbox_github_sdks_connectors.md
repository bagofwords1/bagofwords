# Glassbox (glassbox.com, formerly Clarisite) — GitHub, SDK/package and connector footprint

Research date: 2026-11-17. Scope: public code, packages, connectors and any API detail usable for a read-only Python connector.
Method: GitHub repository + code search (authenticated `gh api search/...`), direct registry API queries (npm, PyPI, pub.dev, NuGet, Maven Central, CocoaPods trunk), anonymous read of Glassbox's own JFrog Artifactory, web search and page fetches. No files were written to any remote system.

Legend: **[V]** = verified directly against the primary source on 2026-11-17; **[S]** = secondary source / search snippet only; **[I]** = inference.

## Which GitHub organizations/users belong to Glassbox, and what public repos exist?

### Takeaway
Glassbox has **no discoverable public GitHub organization or open-source repository**. Its code is distributed through a vendor-run JFrog Artifactory (`glassbox.jfrog.io`), not GitHub; the only GitHub hits are a handful of third-party customer/test repos and thousands of blocklist/tracker-database entries.

### Gaps

## What SDKs/packages are published, where, and what do they reveal?

### Takeaway
**Nothing is on the public registries** (npmjs, pub.dev, CocoaPods trunk, Maven Central, nuget.org, PyPI). Everything is on an **anonymously readable vendor Artifactory at `https://glassbox.jfrog.io/artifactory/`** with 15 repositories; all mobile artifacts share one version line, latest **7.3280.0 published 2026-11-05**. These SDKs are capture-side only (they send data *to* Glassbox); none exposes a read/query API.

### Inferences
- **[I]** Version scheme is `<major>.<build>.<patch>` shared across all platforms and released in lock-step (same day, 2026-11-05, for npm/pub/NuGet/Maven), roughly every 1-3 weeks.
- **[I]** Tenant hostnames follow `report.<tenant>.gbqofs.io` (ingest), `cdn2.gbqofs.com/<tenant>/` (tag CDN) and `console.<tenant>.glassboxdigital.io` (UI) for SaaS; on-prem/private-cloud customers use their own hostnames. The tenant slug and app GUID from the report URL are likely the same identifiers the console uses, but no source confirms that for a read API.
- **[I]** None of this is directly useful for *reading* data: the SDKs are write-only. Their value to a connector builder is naming (appId GUID, `cuid`, session id, `_cls_s`, custom event name + flat primitive params) so that exported records can be interpreted.
- **[I]** The Artifactory contains files named `.write-probe.txt`, `pentest-probe.txt`, `test-probe.txt`, `test-anon-<n>.txt` in two repos, which suggests third parties have tested anonymous write access. Treat artifacts from this host as a reference for documentation only, and pin/verify checksums if anything were ever consumed from it.

### Gaps
- `SwiftPackages` latest version not resolved (listing order is lexical; highest seen 7.2210.1 may not be the newest).
- iOS podspec contents, NuGet nuspecs, Capacitor/NativeScript/KMP READMEs and the `MobileAppExamples` zips were not opened.
- Earliest publish dates for the npm packages are unreliable in the registry `time` map (null entries); folder creation 2021-09 is the best available floor.
- No public web-SDK npm package exists; the browser tag is served per-tenant from the CDN only.

## Are there API clients, Postman collections, OpenAPI specs, Terraform providers, CLIs or samples calling Glassbox server-side/reporting/export APIs?

### Takeaway
**None found.** No public OpenAPI/Swagger file, Postman collection, Terraform provider, CLI, or API client library for Glassbox's read/export side exists in any searched location; the only public code that "reads" Glassbox data does so by **driving the web console with Selenium**. Official API documentation sits behind the customer login at `support.glassbox.com`.

## Do data-integration tools have a Glassbox connector?

### Takeaway
**No ELT/reverse-ETL/iPaaS connector for Glassbox was found** (Airbyte, Fivetran, Singer/Meltano, Stitch, dlt, Airflow, Rivery, Hevo, CData, Census, Hightouch, Zapier, Make, n8n). ### Cited Findings
- **[V]** GitHub repo/code search: zero hits for `glassbox airbyte`, `source-glassbox`, `tap-glassbox`, `glassbox segment`, `glassbox tealium` (repos). Web search for a Glassbox connector across Airbyte/Fivetran/Segment/mParticle/Tealium/Adobe/Snowflake returned no Glassbox-specific result. — [GitHub code search](https://github.com/search?q=%22source-glassbox%22&type=code)

Setup doc is the gated article `support.glassbox.com/hc/en-gb/articles/4405777280401-How-to-Connect-New-Relic`. — [newrelic-quickstarts quickstarts/glassbox/config.yml](https://github.com/newrelic/newrelic-quickstarts/blob/main/quickstarts/glassbox/config.yml); [dashboard.json](https://github.com/newrelic/newrelic-quickstarts/blob/main/dashboards/glassbox/dashboard.json); [New Relic listing](https://newrelic.com/de/instant-observability/glassbox)

- **[S]** Survicate has a Glassbox integration that adds a "Glassbox URL" (recording link) column to survey responses; requires both snippets on the page. — [Survicate help](https://help.survicate.com/en/articles/3942551-glassbox-integration)

- **[V]** Glassbox's own integrations page lists: Adobe Analytics, Google Analytics (GA4), Blue Triangle; New Relic, Dynatrace; Google Tag Manager, Adobe Launch, Tealium, Ensighten; SurveyMonkey, Qualtrics, Medallia; Jira, Slack, Firebase; AB Tasty, Adobe Target, Optimizely, Monetate, SiteSpect, VWO, Dynamic Yield, Kameleoon. - **[I]** Every observed integration follows the same pattern: expose the Glassbox session id (cookie `_cls_s` on web, `getSessionId()` on mobile) and/or a replay deep link to the partner tool. - **[I]** With no prior-art connector, there is no reference implementation for stream names, incremental cursors, or auth; a Python connector would be greenfield and dependent on customer-portal documentation.
