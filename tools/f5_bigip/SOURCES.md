# F5 BIG-IP connector — evidence log

Target contract: **iControl REST on TMOS 15.x–17.x** (simulator reports 17.1.1). Every
wire shape in `simulated_api.py`, `catalog.json` and `f5_bigip_client.py` is tagged
below as **verified** (quoted from an official document, F5 code, or a real response
fixture), **partial** (structure verified, some key names not), or **inferred**
(endpoint known to exist, exact key names reconstructed from `tmsh show` output or
secondary sources). Nothing was silently invented; inferred tables say so in their
descriptions and the client flattens whatever keys the device returns for them.
