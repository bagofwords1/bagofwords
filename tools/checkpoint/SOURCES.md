# Check Point Management API — evidence used for the connector and simulator

Contract: Management Web API **v1.9.1** (R81.20 JHF Take 43). The same shapes were
cross-checked against the **v2** reference data (R82). Everything marked
**verified** was read from one of the sources below; everything marked
**inferred** could not be confirmed from a primary source and is called out so a
customer validation pass knows where to look.

## Deliberate deviations in the simulator

* `generic_err_wrong_session_id` / `generic_err_missing_session_id` / `generic_err_session_expired` answer with HTTP 401 (see above).
* `show-changes` always completes synchronously (reference example form); the client still supports the `task-id` + `show-task` form.
* Only one domain exists; a `domain` login value other than that domain's name or UID fails with `err_login_failed`.
* `logs-count` is a JSON string, mirroring the reference example, although the reply object declares an integer.
